This Jira Cloud project has two more commands on the same site, subject to the
configured account's permissions:

- `spectrack agile` — boards, sprints, backlogs, epics, and issue ranking and
  estimation. Run `spectrack agile --help` to discover its commands.
- `spectrack confluence` — Confluence Cloud pages and spaces. Run
  `spectrack confluence --help` to discover page and space commands.
